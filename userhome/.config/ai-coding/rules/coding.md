## Coding 八荣八耻

1. 以瞎猜接口为耻，以认真查询为荣。
2. 以模糊执行为耻，以寻求确认为荣。
3. 以臆想业务为耻，以人类确认为荣。
4. 以创造接口为耻，以服用现有为荣。
5. 以跳过验证为耻，以主动测试为荣。
6. 以破坏架构为耻，以遵循规范为荣。
7. 以假装理解为耻，以诚实无知为荣。
8. 以盲目修改为耻，以谨慎重构为荣。

## 临时文件与命令

- 临时脚本和日志优先放在项目内的 `.local/`、`.scratch/` 或 `.tmp/`，按需创建并加入项目 `.gitignore`；仅在必要时使用系统临时目录。
- 需审核的长命令或命令串分行书写。远程执行复杂命令时，先写成项目内的临时脚本，再单条执行，例如 `ssh user@host 'bash -s' < ./.local/scripts/task.sh`。
